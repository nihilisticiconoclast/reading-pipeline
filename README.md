# reading-pipeline
Get Claude Code to make book recommendations

A weekly Claude Code routine that proposes additions to my to-read list,
biased toward expanding rather than reinforcing my current reading habits.

- `reading.md` — books currently being read
- `read.md` — books read, with one-line verdicts where I have them
- `abandoned.md` — books started and given up on (used as a negative signal)
- `owned.md` — full bookshelf catalogue
- `to-read.md` — suggestions queue (appended to by the routine)
- `reading-persona.md` — taste profile that drives the routine's recommendations
- `digest/YYYY-WW.html` — weekly digest from the routine (auto-generated)
- `index.html` — GitHub Pages home, listing all digests
