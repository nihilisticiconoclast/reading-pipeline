# reading-pipeline
Get Claude Code to make book recommendations

A weekly Claude Code routine that proposes additions to my to-read list,
biased toward expanding rather than reinforcing my current reading habits.

- `read.md` — books read, with one-line verdicts where I have them
- `to-read.md` — suggestions queue (appended to by the routine)
- `digest/YYYY-WW.md` — weekly digest from the routine (auto-generated)
